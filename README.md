# InterviewAI

AI-powered mock interview platform designed to help users practice technical interviews and improve their interview performance.

InterviewAI generates interview questions, evaluates answers, provides personalized feedback, and keeps track of previous interview sessions.

## Features

- AI-generated interview questions
- Multiple interview tracks and difficulty levels
- AI-powered answer evaluation
- Interview feedback and scoring
- Interview history
- User authentication
- Responsive user interface

## Tech Stack

**Frontend:** React.js, Vite, CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose  
**AI:** Ollama, Phi LLM  
**Authentication:** JWT, bcrypt  
**Deployment:** Vercel, Render

## Architecture

React Frontend
       |
       v
Node.js + Express
       |
       +-------> MongoDB
       |
       v
Ollama + Phi LLM
